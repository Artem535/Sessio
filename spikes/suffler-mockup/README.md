# Макет: классический вид суфлёра, доведённый до ума (на согласование)

Открыть: [`mockup.html`](mockup.html). Самодостаточный, данные обезличены (Проект А/Б/В).

**База — классический вид** (бумага в центре, транскрипт справа, видео-полоса сверху).
Радикальную перекладку (компактный список справа + вложенная панель + полоска имён)
отклонили и откатили (`38e8b7b7`); здесь улучшаем именно классику.

Состояния:
- `mockup.html` — «Классический · доведённый».
- `mockup.html#expanded` — раскрыта первая контекст-карточка (полный ответ inline).
- `mockup.html#current` — «Классический · текущий» (как в приложении сейчас) для сравнения.
- «+ симулировать реплику» — новый контекст добавляется сверху списка.
- Переключатель в шапке сравнивает доведённый и текущий.

## Что меняем в классике (доведённый вид)

1. **Все контекст-карточки, а не одна верхняя.** Секция «Wiki hints · контекст» —
   список карточек (бейдж Проект/Вопрос/Wiki + заголовок + 2 строки превью + давность),
   новые сверху, старые ниже, счётчик. Пустое состояние «Пока нет контекста».
2. **Полный ответ inline.** Клик по карточке раскрывает её же на месте (аккордеон):
   полный markdown (заголовки/списки/bold) + «Open page ↗» + источник. Без модалок и
   без второй панели — раскладка не прыгает, бумага просто удлиняется.
3. **Транскрипт открыт по умолчанию** во время звонка (сейчас скрыт за кнопкой
   «Open transcript»); поиск и «✕» сохраняются.
4. **Визуальная полировка**: единые радиусы/отступы/типографика, бейджи типов,
   давность, пустые состояния, аккуратные кнопки действий.
5. Договорённости и clarify остаются как есть (Accept/Edit/Dismiss, Hide).
6. Видео-полоса и участники — без изменений (классика).

## Что НЕ меняем

- Раскладку колонок (центр-бумага / правый транскрипт / видео сверху).
- Логику суфлёра (retrieval v2, обогащение, резолвер, CoT-rewrite) — она отдельна и сохранена.
- Дефолт до согласования: текущий классический вид.

## Открытые вопросы

1. Аккордеон inline vs модальное окно для полного ответа: inline не прыгает layout,
   но удлиняет бумагу; модалка даёт большое поле без прокрутки бумаги. Что ближе к референсу?
2. Превью в списке: 2 строки snippet достаточно, или только заголовок + бейдж?
3. Показывать ли давность («только что / 10 с») или score релевантности?
4. Транскрипт по умолчанию открыт — ок, или оставить кнопку (меньше шума на узких окнах)?
5. Секция контекста внутри Prompter-блока (как в макете) или отдельным блоком ниже?
