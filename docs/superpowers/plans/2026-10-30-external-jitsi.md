## Запись выполнения

- Добавлены парсер `jitsi_url`, ExternalJitsi, явный вход по ссылке в QWidget/QML, настройка сервера, локальное создание календарной комнаты, прямое приглашение и встроенный маршрут календаря/«Моего дня». Сигналы передают event ID для привязки материалов; ручной вход остаётся без события.
- Решение: миграция не нужна — `provider_kind TEXT` без ограничения значений, существующие nullable поля достаточны. Добавлен тест закрытия/повторного открытия базы с ExternalJitsi без meeting_ref/invitation_state.
- Решение: пароль не реализован в первом объёме; password/auth/lobby завершают подключение с понятным сообщением, доступно отдельное явное открытие ссылки в браузере. Не отвечает сервер/не завершился вход — ограничение ожидания 30 секунд.
