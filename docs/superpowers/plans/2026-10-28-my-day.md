# "My day" Home Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a «Мой день» start tab: four stat tiles, a morning/afternoon/evening timeline of the day, and a day to-do column with carry-over.

**Architecture:** Pure C++ logic (`my_day_logic`) turns projected `DuckEvent`s + notes + "now" into tiles and timeline items; a `MyDayBridge` QObject feeds that and DuckDB-backed to-dos to a QML page hosted in a `QQuickWidget` (same pattern as `TranscriptListPage`). Meetings are read through the shared `QTimelineModel::eventsForRange`, never `loadEventsForDay`.

**Tech Stack:** C++20, Qt 6 Widgets + Quick/QuickWidgets/Qml, DuckDB, GoogleTest + Qt6::Test.

**Spec:** `docs/superpowers/specs/2026-10-28-my-day-design.md` — read it first; this plan does not repeat its UI rules.

## Global Constraints

- Build only against the prebuilt tree, never let vcpkg rebuild deps (DuckDB): use the existing `build-release` dir (`PCM_BUILD_TESTS=ON`, Ninja). - Launch the GUI only via `scripts/run-dev-isolated.sh`; never kill a running Sessio.
- "Active" event = `event_stat_id IN (1, 2, 4)`. Pending payment = `payment_stat_id = 1`.
- Sections: Утро `< 12:00`, После полудня `12:00–17:59`, Вечер `>= 18:00` (local start time).
- Windows: Unpaid = ended within the last **90 days**; Without notes = ended within the last **7 days**. "Ended" = `end_date < now`.
- Currency from `pcm::widgets::settings::currencySymbol()`.
- All user-facing strings via `tr`/`qsTr`; add ru/en entries to `translation/app_ru.ts` / `app_en.ts`. Tab label key `": NAV_MY_DAY"` → «Мой день» / "My day".
- Every new test file gets its own `add_executable` + `gtest_discover_tests` block in `test/CMakeLists.txt`, named `Sessio_<file stem>`; fixture names `DayTodoDbTest`, `MyDayLogicTest`, `MeetingJoinTest`, `MyDayBridgeTest`, `MyDayPageTest`, `MainWindowMyDayTest`, so the `ctest -R` regexes below match.
- New files follow the surrounding style (4-space QML, 2-space C++, `pcm::` namespaces, `m`-prefixed members).

## Review Focus

1. A recurring series occurrence that was never opened (virtual, negative id) — must appear in the timeline, count in Unpaid/Without-notes, jump to the Calendar, and accept a to-do link. → Task 3 test `virtualOccurrenceCountsAsUnpaidAndWithoutNote`, Task 6 test `openEventPassesVirtualIdToCalendar`.
2. An event crossing midnight (23:30–00:30) — shows on both days, in Вечер on the first and Утро on the second. → Task 3 test `midnightCrossingEventShowsOnBothDays`.
3. Opening «Мой день» must not change the Calendar's loaded day. → Task 6 test `loadingDayDoesNotMoveCalendarModel`.
4. A to-do carried over from an earlier day and then finished — shows on today only, never on two days; counter counts shown rows. → Task 1 test `finishedCarryOverShowsOnlyOnFinishDay`.
5. The linked meeting or client of a to-do disappears (event deleted, occurrence moved, client deleted) — to-do survives in «Общие». → Task 1 test `deletingEventUnlinksTodo`, Task 4 test `todoWithMissingMeetingFallsToGeneral`.
