# calendar-layout reference images

`month.png` and `day-small.png` are the **earlier prototype** of the calendar layout (title, period
row, right-hand inspector panel, light theme). They are **superseded** by the owner-approved design
implemented in commits 6a73698 and 7bfb825: Day|Switch|Month and "New meeting" in the main window's
top row, a left column with the calendar card (day calendar / month picker), one info card (day
summary / meeting inspector) and quick slots, and the day timeline or month grid in the centre.
The PNGs are kept only as history of the information design of the inspector and month chips.
