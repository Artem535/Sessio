# Проверка #102: календарь с режимами «День» и «Месяц»

Ветка `codex/102-calendar-month-layout`, версия 0.2.9. Схема БД и сервер не менялись.

## Что сделано (визуальная доработка по отклонённому макету)

- Компоновка страницы возвращена к исходной: слева колонка ~400 px (карточка
  календаря, одна переключаемая информационная панель, быстрые слоты), по центру —
  исходная дневная шкала или месячная сетка. Заголовка страницы, строки периода
  и правой колонки больше нет.
- Переключатель День / Месяц (`oclero::qlementine::Switch`) и кнопка «New meeting»
  размещены в верхней строке главного окна (`pageCustomWidgetHost`), доступ —
  `QEventInfoPage::headerControls()`, регистрация в `MainWindow::addEventInfoPage`.
- В режиме «День» карточка — исходный `RoundedCalendarWidget` (восстановлен);
  в режиме «Месяц» на том же месте — выбор месяца (`MonthPickerWidget`: «‹ 2026 ›» и 12 плиток).
- Информационная панель: сводка дня или инспектор встречи (метки Date / Time / Repeat /
  Delivery format / Status над значениями, кнопки на всю ширину: Copy invite — основная
  для онлайн-встречи, Open, Edit; «Back to day» в углу карточки). Панель прокручивается внутри.
- Месячная сетка: число выбранного дня видно (плашка-круг, ранее текст скрывался
  у checked-кнопки), сегодня — кольцо, соседние дни приглушены, плашки событий
  (точка, время, название; акцент для рабочих, нейтральный для личных),
  тонкие линии сетки, строки не ниже 112 px, без верхнего предела.
- Дневная шкала прокручивается к первой встрече дня (или 08:00), если она не видна.
- Правки после проверки живого приложения: группа «День / Switch / Месяц» и «New meeting»
  вместе у правого края верхней строки; названия месяцев в выборе месяца единообразно
  из 3 букв («Sep», «Сен»); месячная сетка заполняет высоту центра (строки не ниже 112 px, без верхнего предела,
  низ сетки выровнен с низом левой колонки); сводка дня и инспектор встречи лежат
  в ОДНОЙ карточке (`infoPanelCard`), заголовок дня — выбранная дата; подписи дней недели
  выровнены по левому краю с номерами дней.
- Версия 0.2.9, запись в `CHANGELOG.md` обновлена.

## Выравнивание низа сетки с левой колонкой (после проверки в живом окне 2000x1220)

Низ месячной сетки, дневной шкалы и левой колонки (низ быстрых слотов) совпадает на
2000x1220, 1920x1080, 1500x900, 1275x1395, 1100x720, для месяцев из 5 строк (окт. 2026)
и 6 строк (март 2026; на 1100x720 6-строчная сетка выше окна и прокручивается).
Измерено на настоящем `MainWindow` (offscreen, только страница календаря; поля, строка состояния, навигация —
как в приложении), а не только на макете. Причина зазора ~70 px в живом окне:
верхний предел высоты строки (160, затем 260 px) — при экранном масштабе ~1.25
160 px = 200 px, как и измерил заказчик (~203 px). Предел убран: строки делят всю
высоту поровну (минимум 112 px).

## Скриншоты

Снимки сняты на настоящем `MainWindow` (offscreen, `QWidget::grab()`): в него добавлена только страница календаря (`addEventInfoPage`), без остальных страниц и без `SeriesCallService`; поэтому видны навигация слева, верхняя строка с `headerControls()` и строка состояния, но нет данных звонков.

Настоящий `QEventInfoPage` в окне, имитирующем главное окно (заголовок «Sessio» и
верхняя строка с `headerControls()`), реальная тема Qlementine Dark, offscreen,
`QWidget::grab()`, синтетическая БД (еженедельная серия LiveKit по четвергам, личные
встречи по вторникам, плотный день из 8 встреч, ночная встреча, внешняя ссылка,
встречи очно). «Сегодня» — дата съёмки. Приложение всегда использует Dark, светлых вариантов нет.

## Сравнение с эталонами (`docs/design/calendar-layout/*.png`) и отличия

- Инспектор: заголовок «Meeting», название, мелкие приглушённые метки над значениями,
  длительность отдельной строкой, кнопки на всю ширину, карточка с рамкой — как в эталоне.
  Статус синхронизации серии и подсказка «Use one link…» появляются только при подключённом
  `SeriesCallService`; в harness его нет, поэтому на снимках их не видно.
- Плашки событий двухстрочные (время, затем название), а не однострочные: при ширине центра
  ~600 px ячейка 85 px, иначе название исчезает. Высота строки (≥112 px, растягивается по высоте окна; эталон ~128).
- Цвета — тёмная тема приложения (акцент `Highlight` для рабочих, нейтральный для личных).
- Дневная шкала — исходная (две колонки, пунктир по центру); в рамках этой правки не
  перерабатывалась; добавлена только автопрокрутка.
- При 900 px высоты кнопки Open/Edit инспектора уходят ниже видимой области панели
  (прокручивается внутри); при 1395 px видны целиком.
- Тест, закрепляющий интеграцию `headerControls()` в настоящем `MainWindow`, не добавлен: ему нужны все зависимости главного окна (страница звонков); интеграция проверена снимками.
- Окно 1100x720: ячейки месяца ~60 px, названия усечены до 3-4 символов.
- Цвета выбранного дня/месяца в карточках (RoundedCalendarWidget, MonthPickerWidget) — исходная
  фиксированная синяя плашка, не палитра темы.
- Имена месяцев/дней недели в `RoundedCalendarWidget` берутся из системной локали
  (поведение исходного виджета); сетка и плитки месяцев — из локали приложения.

## Не проверено / ограничения

- Реальный медиа-smoke видеозвонка не выполнялся; unit-тесты не доказывают работу медиа.
  Проверяется только маршрутизация открытия встречи (meeting ref).
- Устаревший async-ответ keychain при смене выбора юнит-тестом не покрыт
  (нет шва для подмены `SeriesCallService`); защита реализована в коде.
- Ошибка чтения `canceled_by` — отдельный issue #104, не относится к #102.
- N2 (minor): перенос выбранной встречи на другой день в дневном режиме сбрасывает выбор.
- Скриншоты сняты offscreen на Linux; Wayland/реальное окно и HiDPI не проверялись.
  Harness не добавлен в репозиторий.
- Независимое whole-branch review, push и PR в этой задаче не выполнялись.
