# Проверка #105: диалог выбора роли при первом запуске

Скриншоты сделаны офлайн-харнессом (QT_QPA_PLATFORM=offscreen, QWidget::grab()) на реальном
виджете `RoleSelectionDialog` с темой Qlementine Dark из `resources/themes`.

- `role-dialog-dark-en.png` — английская локаль.
- `role-dialog-dark-ru.png` — русская локаль (перевод из `translation/app_ru.ts`).

Проверено: фиксированный размер 420x220, вопрос выровнен по центру, кнопки одинаковой ширины
(200–260 px) по центру, русские строки не обрезаются.

Ограничения: скриншоты не из запущенного приложения (харнесс не входит в репозиторий);
отсутствие кнопки «развернуть» на реальном окне зависит от оконного менеджера — в автотестах
проверяются фиксированный размер (min == max) и снятый флаг WindowMaximizeButtonHint.
