# Проверка #107: цвета событий в месячном представлении

Скриншоты сделаны офскрин-харнессом на реальных виджетах `QEventInfoPage` с тёмной темой Qlementine, окно 1500x900, дата 14.10.2026 (рабочая сессия 10:00 и личное событие 14:00, плюс несколько событий в соседних днях).

- `day-default.png` / `month-default.png` — цвета по умолчанию (синий для рабочих, фиолетовый для личных). Чипы месяца совпадают с блоками дневной шкалы.
- `day-custom.png` / `month-custom.png` — пользовательские цвета (зелёный рабочий, оранжевый личный). Те же события в Day и Month одного цвета.

Что проверено:
- заливка чипа = цвет из настроек, граница = `color.darker(165)` (как в дневной шкале);
- цвет текста выбирается по яркости заливки (светлый или тёмный), точка берёт цвет текста;
- после смены цветов `QEventInfoPage::refreshAppearance()` обновляет чипы без перезапуска (цвета читаются из QSettings при каждом обновлении);
- меню «+N», инспектор, бейдж выбранного дня, возврат фокуса и сокращение текста не затронуты (тесты проходят).

Ограничения:
- дневная шкала всегда рисует текст белым, на светлых цветах чип месяца использует тёмный текст ради контраста (на оранжевом это видно);
- месячная сетка не различает статусы (отменено и т. п.), как и раньше; логика не добавлялась;
- чипы онлайн-встреч без флага рабочего события теперь считаются личными, как в дневной шкале.
