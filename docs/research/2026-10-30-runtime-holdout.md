# Runtime repair и независимые сценарии

До запуска Holdout* зафиксированы четыре случая: отказ от доставки образцов,
встреча с мастером по ремонту, завершённое восстановление архива без будущей
задачи, решение о библиотеке среди приветствий. Их имена, темы и формулировки
не включены в prompts. Результаты не использовать для новой редакции prompts:
после просмотра набор считается открытым, новая калибровка требует нового набора.

Сначала проверить development-приём с примером G после runtime repair.
Затем один запуск 14 development/regression + 4 Holdout* на CPU.
Sampling/thinking прежние. Отдельно проверить минимальный constrained enum на
фактическом GPU, не смешивать CPU/GPU метрики. Это небольшая проверка переноса,
не оценка произвольных разговоров и не доказательство общего роста качества.

До исправления enum Анна/Борис падал с forced-byte D0/EF. Только string-mode
убрал эту ошибку, но результат оставался незавершённым JSON. Таблица GetTokens
содержала SentencePiece pieces, а llguidance требует decoded token bytes.
Исправлена таблица byte-fallback/metaspace, включён string mode, singleton stop
tokens помечены как special. Enum и перенос после этого прошли, личный приём
в B1 по-прежнему пропущен. Пример G повторно проверяется на исправленном runtime.
