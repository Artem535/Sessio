== Modules

=== `src/app`

- `application.*`
: app bootstrap and cross-page/business signal wiring.
- `main_window.*`
: root shell window, page registration, navigation, top custom widget host.

=== `src/config`

- `Config`
: YAML-backed app config.
- `DatabaseConfig::db_pth`
: DB directory path.
- `rfl_path.hpp`
: `Poco::Path` reflector for `rfl` serialization.

=== `src/database`

- `Database`
: CRUD for `Client` and `Event`, relation management (`EventClient`), conflict/day queries.
- `constants.hpp`
: SQL schema + seed statuses + demo data.
- `schema.hpp`
: DTO structs (`ObxClient`, `ObxEvent`, etc.) constructed from DuckDB chunks.
- `db_utils.hpp`
: value conversion helpers between DuckDB and C++ optional types.

=== `src/meeting`

- `ProviderKind` (provider_kind.h)
: enum identifying which meeting provider backs an `Event`/`EventSeries`
  (`ExternalUrl`, `LiveKit`), with string round-trip helpers.
- `MeetingDescriptor` (meeting_descriptor.h)
: value type describing a created meeting (kind, ref, URL, invitation state).
- `MeetingProvider` (meeting_provider.h)
: abstract, signal-based interface (`create`/`cancel`) that every provider
  implements.
- `ExternalUrlMeetingProvider`
: today's behavior — wraps a practitioner-supplied http(s) link, no network
  I/O.
- `LiveKitMeetingProvider`
: non-functional stub for the real LiveKit token-backend integration.
- `MeetingCoordinator`
: selects and drives the right `MeetingProvider` by `ProviderKind` on behalf
  of the event-editing UI.

=== `src/video`

- `VideoProvider`
: abstract interface over the in-call media session (join/leave, local
  capture, remote render) — one production implementation,
  `LiveKitVideoProvider`.
- `LiveKitVideoProvider`
: connects to a LiveKit server, publishes local camera/microphone tracks,
  and renders/plays the first subscribed remote video/audio track.
- `VideoSession`
: owns the call lifecycle for one Meeting, translating `VideoProvider`
  signals into `VideoSessionState` transitions via a `QStateMachine`. Knows
  nothing about `Event`/persistence.
- `VideoSessionState`
: the enum driving `VideoSession` (`NoMeeting` through `Ended`/`Failed`).
- `DeviceManager`
: enumerates and selects the camera/microphone/speaker via Qt Multimedia,
  independent of `VideoProvider`.
- `VideoCaptureAdapter`/`VideoCaptureWorker`
: camera capture, with frame conversion and the LiveKit FFI call offloaded
  to a dedicated worker thread.
- `AudioCaptureAdapter`
: microphone capture, running on the GUI thread in LiveKit's real-time
  (non-buffered) capture mode.
- `RemoteVideoRenderer`/`RemoteAudioPlayer`
: render/play a subscribed remote track, pulling frames on a dedicated
  `std::thread`.

=== `src/backup`

- `BackupService`
: builds a `.psybackup` zip (consistent DuckDB export via
  `Database::export_snapshot`, optional attachments, SHA-256 checksummed
  `manifest.json`), finalized with a same-directory temp file + atomic
  rename.
- `BackupValidator`
: re-verifies a `.psybackup` file's manifest and per-entry checksums.
- `RestoreService`
: validates a `.psybackup`, imports its DuckDB snapshot into a staging directory,
  and replaces the configured database and optional attachments directory only
  after validation succeeds. Existing directories are retained as
  `.pre-restore-<uuid>` protective copies. The application must close active
  database connections before replacement.
- `backup_manifest.hpp`
: `BackupManifest`/`BackupEntry` DTOs (rfl JSON).
- `checksum_utils.hpp`
: `sha256_file` via `Poco::SHA2Engine`.

=== `src/client_model`

- `QClientModel`
: `QAbstractListModel` for clients; async loading on worker thread.
- `QClientDelegate`
: custom card-like rendering and action hit-testing for list rows.

=== `src/pages/client_info_page`

- `ClientInfo`
: page with `QListView` bound to `QClientModel`.
- reacts to loading state and delegates "display" action.

=== `src/pages/event_info_page`

- `QEventInfoPage`
: calendar + timeline + event dialog orchestration.
- `QEventDetailsWidget`
: create/edit event form, validation, emits save/cancel/link signals.

=== `src/pages/detail_client_info_page`

- `QClientInfoCardPage`
: editable detailed client form.
- `QClient`
: Qt-friendly wrapper around `ObxClient` (conversion + computed age).

=== `src/event_view`

- `QTimelineModel`
: timeline data model for events of selected day.
- `QEventView`
: graphics view scene, timeline background/axis, item placement.
- `QEventItem`
: interactive event graphics object.

=== `src/timeline_widget`

- `QTimelineWidget`
: composition widget that connects `QEventView` with `QTimelineModel`.

=== `src/widgets`

- `TabButton`
: custom painted navigation button.
- shared UI constants.
